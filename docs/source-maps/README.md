# Agentic Engineering source-map seed pack

Snapshot: 2026-07-16 UTC

These are research inputs for the first self-expanding Agentic Engineering corpus cycle. They are evidence-ranked candidate maps, not automatically promoted doctrine or proof that every source should be deeply ingested.

- `scientific-benchmark-foundational.md` — scientific evaluations, benchmarks, and distributed-systems foundations.
- `creator-operator-expansion.md` — builder, maintainer, researcher, and operator graph.
- `production-evidence-postmortems.md` — production reports, incidents, postmortems, reliability, and security evidence.

## Promotion rule

A candidate becomes a canonical source only after the shared engine records:

1. a stable canonical locator;
2. source and evidence lane;
3. authority and incentive classification;
4. refresh cadence;
5. rights/access state;
6. inspectable evidence or first-party artifact;
7. explicit promotion decision or a passing automatic promotion gate.

## Provenance

Generated by three read-only Hermes research workers on 2026-07-16. Workers used direct canonical sites, scholarly APIs, GitHub APIs, X discovery, and public YouTube metadata. General Firecrawl-backed web search was unavailable, so sources requiring direct confirmation remain candidates until the acquisition worker verifies them.

Raw delegation receipts are retained under the local Hermes delegation cache. These copied summaries are the tracked, secret-free corpus-engine inputs.
